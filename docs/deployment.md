# Deployment checklist
- Use managed PostgreSQL and persistent media/object storage.
- Set strong secrets and real Paystack keys in the host environment.
- Use HTTPS, secure cookie settings, trusted proxy settings and a restrictive CORS policy.
- Configure SMTP/email provider for confirmations and password resets.
- Configure backups, monitoring, rate limits and payment webhook URL.
- Test concurrency, payment callbacks and cancellation/refund policies before launch.
